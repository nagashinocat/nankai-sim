# 和歌山県 全壊棟数の照合（2026-11-12）

本アプリの方法（内閣府 R7 データセットAの震度・液状化 × 建物ストック × 被害関数）で計算した全壊棟数を、和歌山県が公表した市町村別の全壊棟数と比べた結果。構成は docs/reports/2026-11-12-tokai-reconcile.md と同じ。

## 方法

- 公表値: 和歌山県 地震被害想定調査 報告書（概要版）平成26年3月 p.17「建物被害の予測結果 南海トラフ巨大地震 冬18時 風速8m」の列「揺れ等による全壊棟数」（data/published/30_municipal.csv、30市町村、合計 85,392。全県の概数 約84,700）。
  https://www.pref.wakayama.lg.jp/prefg/011400/d00153668_d/fil/wakayama_higaisoutei.pdf
- **定義の違い（Ruling W-a）**: 県の「揺れ等」は液状化・震動・斜面崩壊を含む。本アプリは揺れのみが基本だが、和歌山県では揺れと液状化の全壊率を合成して比べる（メッシュの沈下量があれば 1−(1−揺れの全壊率)(1−液状化の全壊率)。アプリの自宅の計算と同じ合成）。斜面崩壊は本アプリに無いので含まない。参考として揺れのみの値も載せる。
- ケースの対応（ルール）: 県の地震動は内閣府2012年モデルの陸側ケース → `L2_RIKU`（内閣府ケース2）。参考に `L2_KIHON`（ケース1）も計算した。
- 市町村の合否: 計算値 / 公表値 が 1±0.3 に入れば合格。
- 県計の比較: 内閣府の都府県別の値はリポジトリに無いため、`--national` に県の全県の概数 84,700 を渡した（レポート中では「比較値（--national で指定）」と表示）。
- 建物: 令和2年国勢調査メッシュの世帯数で、令和6年度 固定資産の概要調書の市町村別棟数（和歌山県 30市町村 計 642,722 棟）を按分。構造×年代の割合は e-Stat 表6-3-2（和歌山県計と11市町）。白浜町は表の行の2001年以降が 0 のため入れておらず、県計の割合で代用。表の「美浜町」は愛知県の町なので、和歌山県の美浜町には使わない（県計の割合で代用。県のブロックの中だけで引くよう修正した）。県計割合で代用した町村は19。
- 実行したコマンド:
  ```sh
  npx tsx scripts/reconcile.ts --pref 30 --national 84700                           # 揺れ＋液状化（既定）
  npx tsx scripts/reconcile.ts --pref 30 --national 84700 --shake-only              # 参考: 揺れのみ
  npx tsx scripts/reconcile.ts --pref 30 --national 84700 --hazard-case L2_KIHON    # 参考: 基本ケース（揺れ＋液状化）
  ```
  市町村別の表は `reports/reconcile-30-L2_RIKU-liq.md`・`reports/reconcile-30-L2_RIKU.md`・`reports/reconcile-30-L2_KIHON-liq.md`（git 対象外）。

## 和歌山県（L2_RIKU、揺れ＋液状化）

- 県計 87,002 / 約84,700 = 1.03。合格 20/30（下振れ 1、上振れ 9）。
- 液状化の寄与は県計で約2,500棟（揺れのみ 84,488 との差）。合否は揺れのみと同じ市町村。
- 比の大きく外れた5市町村: 有田川町 880 → 2,825（3.21）、日高町 740 → 1,690（2.28）、広川町 530 → 1,139（2.15）、岩出市 600 → 1,231（2.05）、北山村 140 → 25（0.18）。
- ほかの不合格: 那智勝浦町 970 → 1,826（1.88）、日高川町 920 → 1,392（1.51）、有田市 3,700 → 5,213（1.41）、太地町 170 → 238（1.40）、白浜町 2,800 → 3,830（1.37）。
- 棟数の大きい市: 和歌山市 32,000 → 24,909（0.78）、田辺市 10,100 → 10,869（1.08）、串本町 6,500 → 6,596（1.01）、海南市 5,400 → 4,289（0.79）。
- 照合でスキップしたメッシュ（建物はあるが想定値の無い沿岸のメッシュ）: 32。
- 参考: L2_KIHON では県計 56,832（0.67）、合格 9/30。県の陸側ケースとの対応は L2_RIKU の方が近い。

## 既知の違い

- 公表値の「揺れ等」は斜面崩壊を含むが、本アプリには斜面崩壊が無い。北山村（0.18）の下振れは、これや県の地盤モデルの違いによる可能性がある（未確認）。
- 県の報告は平成26年3月（2014年）で、震度は内閣府2012年モデル（陸側）と県の地盤モデル、建物データも当時のもの。本アプリは内閣府 R7 の震度（250m メッシュ）と令和6年度の固定資産の棟数を使う。
- 上振れ9市町のうち6（広川町・日高町・日高川町・白浜町・那智勝浦町・太地町）は、住宅・土地統計に町の値が無く県計の割合で代用した町。
- 住宅・土地統計に市町村の値が無い町村は19（白浜町・美浜町を含む）で、県計の割合で代用している。
- 県境: 三重県と和歌山県の境界が重なる 250m メッシュが1件（5035771714）あり、規則どおり小さい県コード（三重県）を採った。三重県の値は変わらない（県計 165,798、合格 20/29）。
- 市町村名: 愛知県と和歌山県に同名の美浜町があるため、統合後の名前は「愛知県美浜町」「和歌山県美浜町」。照合・到達時間は県名付きの名前で引く（愛知県の照合結果は変わらない）。
