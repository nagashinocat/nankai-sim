# 東海4県 揺れ全壊棟数の照合（2026-11-12）

本アプリの方法（内閣府 R7 データセットAの震度 × 建物ストック × 被害関数、揺れのみ）で計算した全壊棟数を、各県が公表した揺れによる全壊棟数と比べた結果。

## 方法

- ケースの対応（ルール）: **県が使った地震動のケースに合わせる。**
  - 三重県・愛知県: 陸側ケース → `L2_RIKU`（内閣府ケース2）
  - 岐阜県: 内閣府の基本ケース（報告書 §2.1）→ `L2_KIHON`（内閣府ケース1）
  - 静岡県（第4次地震被害想定 第一次報告、2013年6月27日）: 基本ケース（約171,000）→ `L2_KIHON`、陸側ケース（約179,000）→ `L2_RIKU`。市町別の表が無いため県計だけで照合（Ruling T7-b）
- 市町村の合否: 計算値 / 公表値 が 1±0.3 に入れば合格。公表値が「わずか」（愛知の「*」）や 0 の市町村は照合対象外。
- 県計の比較: 内閣府 R7 の都府県別の揺れ全壊棟数は三重県（約157,000）しかリポジトリに無い。愛知・岐阜・静岡は `--national` に県自身の公表値を渡した（レポート中では「比較値（--national で指定）」と表示し、内閣府の値とは書かない）。
- 建物: 令和2年国勢調査メッシュの世帯数で、令和6年度 固定資産の概要調書の市町村別棟数を按分。構造×年代の割合は住宅・土地統計調査（三重は県の第6-3表、ほかは e-Stat 表6-3-2）。
- 実行したコマンド:
  ```sh
  npx tsx scripts/reconcile.ts                                                   # 三重 L2_RIKU
  npx tsx scripts/reconcile.ts --pref 23 --national 222000                       # 愛知 L2_RIKU
  npx tsx scripts/reconcile.ts --pref 21 --national 7773 --hazard-case L2_KIHON  # 岐阜
  npx tsx scripts/reconcile.ts --pref 22 --national 179000 --totals-only         # 静岡 陸側
  npx tsx scripts/reconcile.ts --pref 22 --national 171000 --totals-only --hazard-case L2_KIHON  # 静岡 基本
  ```
  市町村別の表は `reports/reconcile-<県コード>-<ケース>.md`（git 対象外）。L2_RIKU・L2_KIHON のハザードは `build/hazard-reconcile/`（公開しない）から読む。

## 三重県（L2_RIKU）

- 県計 165,798 / 県 約152,000 = 1.09、内閣府 約157,000 = 1.06。合格 20/29（下振れ 3、上振れ 6）。
- 比の大きく外れた5市町: 伊賀市 900 → 3,702（4.11）、菰野町 1,400 → 628（0.45）、多気町 4,200 → 2,221（0.53）、名張市 400 → 676（1.69）、南伊勢町 5,000 → 3,335（0.67）。
- 前回の照合から変わらず（建物・ハザードとも Task 6 の前と同じ値）。

## 愛知県（L2_RIKU）

- 県計 273,642 / 約222,000 = 1.23。合格 25/52（江南市・大口町は公表値が「わずか」で対象外。下振れ 1、上振れ 26）。
- 比の大きく外れた5市町（公表値の小さい尾張北部・東部に集中）: 扶桑町 10 → 107（10.7）、犬山市 10 → 101（10.1）、小牧市 80 → 473（5.91）、瀬戸市 100 → 553（5.53）、春日井市 300 → 1,541（5.14）。
- 棟数の差が大きいのは西尾市 18,000 → 25,240（1.40）、岡崎市 10,000 → 16,961（1.70）、名古屋市 34,000 → 28,265（0.83）、豊橋市 31,000 → 36,559（1.18）、豊川市 11,000 → 16,329（1.48）。
- 公表値が「わずか」の江南市・大口町で、計算は 745 棟・89 棟。
- 参考: L2_KIHON では県計 94,583（0.43）、合格 3/52（下振れ 44、上振れ 5）。県の陸側ケースとの対応は L2_RIKU の方が近い。

## 岐阜県（L2_KIHON）

- 県計 3,662 / 7,773 = 0.47。合格 8/40（飛騨市・白川村は公表値 0 で対象外。下振れ 30、上振れ 2）。
- 比の大きく外れた5市町: 高山市 1 → 0（0.00）、郡上市 131 → 0（0.00）、下呂市 58 → 0（0.00）、美濃市 165 → 13（0.08）、東白川村 4 → 0（0.10）。
- 棟数の差が大きいのは岐阜市 1,730 → 446（0.26）、各務原市 661 → 112（0.17）、海津市 187 → 640（3.42）、土岐市 419 → 94（0.22）、大垣市 934 → 649（0.69）。
- 参考: L2_RIKU では県計 9,449（1.22）、合格 12/40（下振れ 17、上振れ 11）。岐阜県全体で内閣府 R7 のケース1の震度は低め（メッシュ平均の参考震度 4.77、ケース2 では 5.15）。

## 静岡県（県計のみ）

- 陸側: 216,364 / 約179,000 = 1.21。基本: 239,380 / 約171,000 = 1.40。
- 県の想定では陸側の方が全壊が多い（179,000 > 171,000）が、本アプリでは基本（ケース1）の方が多い。内閣府 R7 のデータでは静岡県内のメッシュ平均の参考震度がケース1 6.10、ケース2 6.03 で、静岡県ではケース1 の方が強い。CASES の対応（L2_RIKU = ケース2、L2_KIHON = ケース1）は三重・愛知・岐阜でケース2 の方が強いことと合っており、対応の誤りではなく、県（2013年6月27日の第4次想定 第一次報告）と内閣府（R7）の震源モデルの違いと考えられる。
- 静岡市・浜松市を含む市町村別の計算値は reports/reconcile-22-*.md にあるが、公表値が無いため合否は出していない。

## 既知の違い

- 各県は独自の地盤モデル・震源モデルで計算している。本アプリは内閣府 R7 の震度（250m メッシュ）をそのまま使う。
- 岐阜県の報告は平成23〜24年度（2012〜13年）で、建物データも当時のもの。本アプリは令和6年度の固定資産の棟数を使う。
- 静岡県の第4次地震被害想定（第一次報告）も2013年6月27日の公表で、建物データは当時のもの。
- 愛知県の報告は2026年6月と新しく、建物データの時点は本アプリに近い。それでも上振れは尾張北部・東部の、県の値が数十〜数百棟の市町に集中している。
- 本アプリは揺れのみ（液状化・津波・火災を含めない）。非住宅にも住宅の構造×年代の割合を当てている。非木造は階数を入力しない場合の包絡で計算。
- 住宅・土地統計に市町村の値が無い町村（岐阜11、静岡6、愛知4、三重10）は、県計の割合で代用している。
- 県境: 2県が同じ 250m メッシュを割り当てた例は 0 件（境界の重なりも 0 件）。
