# 菰野町 照合（試算）2026-11-12

本格的なパイプライン（Task 6〜8）の前に、手元のデータで菰野町の揺れによる全壊棟数を試算した。

## 入力
- 震度: 内閣府 データセットA（令和7年）Eq_champ / Eq_1E / Eq_1W の参考震度 Ia。菰野町境界（e-Stat 令和2年国勢調査 小地域境界）内の 250m メッシュ 1,622 個。
- 建物の分布: 令和2年国勢調査 4分の1地域メッシュの世帯総数（町内 15,279 世帯）で按分。
- 構造×年代: 令和5年住宅・土地統計調査 第6-3表 菰野町（住宅数 14,650 戸、建築時期不詳を除く）。
- 被害関数: src/data/fragility.json（内閣府の図から読み取り）。揺れのみ（R12）。

公表値の約3分の1で、合格基準（±30%）を満たさない。結果の数字は変えず、原因を切り分ける。

## 原因の候補（大きい順の見込み）
1. **建物数の母数が違う**: 試算は住宅（戸）14,650。県の想定は非住宅（倉庫・作業小屋・事業所等）を含む全建物（棟）。菰野町の全建物数は住宅数の約2倍程度の可能性があり、そうなら試算は約800〜950棟になる。→ 固定資産の価格等の概要調書（市町村別 木造・非木造 棟数）で確認する。
2. **震度の違い**: 県の L2 は県独自の地盤モデルで、町の面積の 8.5% が震度6強。内閣府データでは世帯で重み付けして 6強は 0.5%（ほぼ全域 6弱、平均 Ia 5.86）。6弱→6強で旧耐震木造の全壊率は数倍になるため、影響は大きい。
3. **年代区分**: 統計の「1980年以前」を pre1981 にまとめているため、1962年以前などの古い区分の割合が分からず、包絡（R8）でも過小になりうる。
4. 被害関数の読み取り誤差（低い値で ±2pt）: 影響は小さい見込み。

## 注意
- 元データ（data/naikaku_raw/）と komono_meshes.json は利用規程に従い git に入れていない。

## 追試: 建物数を全建物（棟）に置き換え（2026-11-12）
固定資産の価格等の概要調書（令和6年度, 総務省）の菰野町: 木造 24,209 棟・木造以外 11,369 棟（計 35,578 棟、住宅統計の約2.4倍）。
