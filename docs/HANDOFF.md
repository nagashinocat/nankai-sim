## 2. できていること

1. **入力**: 住所（国土地理院の住所検索）・現在地・地図でピン／建築年／構造／階数／耐震補強
2. **結果**: 自宅の全壊・半壊（代表値と幅）、周辺1km の推計、避難場所（津波・地震、徒歩時間、間に合うか）、津波（浸水深の段階・到達時間）
3. **想定のタブ**: 最大クラス（L2）／東側・西側の半割れ／時間差（東→西・西→東。国の手法: 先発で半壊した建物は後発で震度+0.5の全壊率。津波は合計に1回だけ）
4. **練習モード**: 南海トラフ地震臨時情報（巨大地震注意）が出た1週間の過ごし方
5. **ひと目でわかる表示**: 震度バッジ、10軒の家、幅の横棒、津波の深さの絵、まとめカード
6. **▶ 地震から津波までを再生**: 揺れ→避難→到達→浸水→まとめ。間に合うかの判定は避難場所リストと同じ
7. **👪 家族の決まり**（`#family`）: 避難先・集合場所・連絡（171/web171）・予定・持ち出す物。端末内だけに保存、文面コピー、印刷用表示
8. **こどもモード**: 「こども／おとな」切替。小学1〜3年向けの言葉・ふりがな・絵
9. **オフライン**: Service Worker でアプリ本体と見たデータを保存。前回の結果（住所・座標なし）を端末に保存
10. **📍 いまいる場所から近い避難場所**（`#near`、branch `near-shelters`）: GPS（押したときだけ・保存しない）から津波・地震の避難場所5件ずつ、簡易地図（SVG、方向と距離、コンパスで向きを合わせる）。結果画面の避難場所にも「🗺 地図」。避難場所のデータ（約3.3MB）を端末に保存すると電波なしでも使える（専用キャッシュ `nankai-offline-shelters-v1`）。電波なしの帯、ホーム画面に追加（manifest・アイコン `scripts/make_icons.ts`）

## 5. 開き方・動かし方

```sh
git clone nankai-sim.bundle nankai-sim   # 引き継ぎフォルダの bundle から
cd nankai-sim && npm install
npm test && npx playwright test          # Chrome が要る（PW_CHROME で指定可）
npm run dev                               # http://localhost:5173（public/data が無いと「対応していません」になる）
```

- `public/data/{hazard,stock,shelters}` は git に入っていない。作り方は `docs/publishing.md` の手順3（生データが要る。引き継ぎフォルダの raw データを `data/raw/` に置く）
- すぐ画面を見たいだけなら、Mac の `nankai-sim-preview` を使う（作り済みのデータ入り）

## 6. 大事な判断（詳しくは docs/superpowers/notes/2026-11-12-core-engine-rulings.md）

- 対応範囲は 250m メッシュ単位（四角が5県の境界と面積>0で重なる）
- 自宅の津波は、その点が浸水域外でも半径50m の8方向に浸水があれば「すぐ近くまで浸水」
- 到達時間: 揺れが収まってから5分で避難開始、ゆっくり歩く速さで比べる。5分以内・不明は「揺れが収まったらすぐ高い所へ」
- 浸水域の場所では「到達時間を待たずにすぐ高い所へ」を必ず出す
- 前回の結果の保存（v4）には想定ケースを含み、住所・座標は含まない
