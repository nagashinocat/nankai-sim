- 出典ページ: https://disaportal.gsi.go.jp/hazardmap/copyright/opendata.html （「重ねるハザードマップ」オープンデータ配信）
- 配信の説明: 「URLからリアルタイムに取得し、ウェブサイトやソフトウェア、アプリケーション等で」商用・非商用を問わず利用可。仕様は地理院タイルに準じる。
- URL（統合版）: `https://disaportaldata.gsi.go.jp/raster/04_tsunami_newlegend_data/{z}/{x}/{y}.png`
- ズームレベル: 2〜17。作成者: 都道府県。40都道府県を掲載（静岡・愛知・岐阜・三重・和歌山を含む）。
- 凡例（`img/shinsui_legend3.png` の画素と、尾鷲・鳥羽のタイルの画素で確認。パレットPNGでアンチエイリアスなし）:

- 浸水域外のピクセルは (0,0,0,0)（透明）。
- **浸水域を含まないタイルは HTTP 404（content-type application/json）** を返す。→ 404 は「浸水域外」として扱う（Ruling T1-a）。
- CORS: `Access-Control-Allow-Origin: *`。別オリジン（disaportal.gsi.go.jp）から fetch → createImageBitmap → OffscreenCanvas.getImageData が成功（2026-11-12、内蔵ブラウザで確認）。
- 利用規約（https://disaportal.gsi.go.jp/hazardmap/copyright/copyright.html 、令和6年12月9日版）: 公共データ利用規約（第1.0版）（PDL1.0）。出典の記載が必要（例「出典：「ハザードマップポータルサイト」」）。編集・加工して使う場合は別に加工した旨を記載（例「「ハザードマップポータルサイト」を加工して作成」）。加工した情報を国が作成したかのように見せない。最新・詳細は市町村のハザードマップを確認するよう案内している。
- アプリでの表示（Ruling T1-b）: 「出典：ハザードマップポータルサイト（津波浸水想定：各都道府県）。浸水深の段階はタイルの色から本アプリが判定（加工して作成）。最新・詳細はお住まいの市町村のハザードマップをご確認ください」
