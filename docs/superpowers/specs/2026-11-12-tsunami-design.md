# 津波の取り込みと東海4県への拡大 設計

親の設計: `docs/superpowers/specs/2026-11-12-nankai-trough-sim-design.md`（§3 データ、§4.3 津波の被害、§5 画面）。この文書はその津波部分を具体化する。

## 1. 目的

自宅の結果に、津波の浸水深・到達時間・津波による被害を加える。津波の避難場所に「すぐ避難を始めれば間に合う可能性」の判定を出す。地図に浸水域を重ねる。周辺の推計に津波分を含める。

## 2. データ

### 2.1 浸水深（ブラウザで読む）

- 元: 国土地理院 重ねるハザードマップ「津波浸水想定」のラスタタイル（都道府県が津波防災地域づくり法に基づき作成した最大クラスの想定）。
- アプリは自宅の位置を含むタイルを1枚取得し、Canvas で該当ピクセルの色を読み、凡例の色から浸水深の段階に変換する。データは持ち直さない（パイプライン不要）。
- 段階（凡例の区分）: 0.3m未満 / 0.3–0.5m / 0.5–1m / 1–3m / 3–5m / 5–10m / 10–20m / 20m以上。色の値は実装時に公式の凡例から確認して定数にする。
- 色が凡例のどれにも一致しない（透明＝想定浸水域の外、または不明な色）→ 前者は「浸水域外」、後者は「判定できない」。
- 着手前の確認（ゲート）:
  1. タイルのURL・ズームレベル・凡例の色を公式ページで確認する。
  2. タイル配信が CORS を許可していて、Canvas で色を読めること（許可されていなければ読めない）。
  3. 利用条件（出典表示を含む）。
  いずれかが不可なら、国土数値情報（津波浸水想定 A40）を 250m マスへ変換する方式に切り替え、この設計を改める。

### 2.2 到達時間（市町ごと）

- 元: 三重県 地震被害想定調査 本編 p.28「沿岸津波到達時間」（L2 理論上最大クラス、市町別、30cm・1m・3m・5m・10m）。
- 安全側に **30cm の到達時間** を使う。「－」（到達しない）は null。
- `data/published/mie_tsunami_arrival.csv`（市町コード, 市町名, 30cm, 1m, 3m, 5m, 10m）に手で書き写し、出典を manifest に記録する。公開用には `public/data/tsunami_arrival.json` を作る。
- 到達時間は「汀線（海岸）に着く最短時間」であり、自宅に着く時間ではない（より早く避難すべき目安として扱う）と画面に書く。

## 3. 計算

- 自宅: 段階の下限と上限の深さでそれぞれ `tsunamiRates` を求め、既存の幅（mode × 震度ずれ）にさらに深さの幅を掛け合わせる。中心値は段階の中央の深さ（20m以上は 20m）。順番は既存どおり 揺れ → 液状化 → 津波。
- 周辺: 各マスの中心で同じタイルから段階を読み、段階の中央の深さで代表曲線（rep）を使う。必要なタイルは最大で数枚。
- 避難の判定（津波の避難場所）: `徒歩時間（遅め） + 避難開始までの時間 5分` と、自宅の市町の 30cm 到達時間を比べる。
  - 間に合う → 「すぐ避難を始めれば間に合う可能性」
  - ぎりぎり（差が5分以内）→ 「ぎりぎり。より近い高い場所も考えて」
  - 間に合わない → 「間に合わないおそれ。近くの高い建物や高台へ」
  - 到達時間が 5分以内、または不明 → 判定は出さず「揺れが収まったらすぐ高い所へ」
- `reachBeforeTsunami` に避難開始時間（定数 `EVAC_START_MIN = 5`）を加える。

## 4. 画面

- 自宅の結果: 「津波 浸水深 1〜3m（想定）・海岸への到達 最短約3分（30cm）」の行を追加。被害の％は津波込み。
- 浸水域の外: 「想定の浸水域の外です。ただし想定を超える津波もあり得ます。海の近くで強い揺れを感じたら高い所へ」
- 判定できない（タイルが読めない・不明な色）: 今の「この結果に津波の被害は含まれていません…」の注意を出す。
- 地図: 津波浸水想定のタイルを半透明（不透明度 0.5 程度）で重ね、凡例と出典を出す。
- 前回の結果（保存）: 浸水深の段階と判定の文言を保存する（座標は保存しない）。

## 5. プライバシー

津波タイルは背景地図と同じ国土地理院から取得する。新しい送信先は増えない。説明ページの記載を更新する。

## 6. テスト

- 色 → 段階の変換（全段階、透明、不明な色）。
- 深さの幅を含む自宅の幅（下限 ≤ 中心 ≤ 上限）。
- 到達の判定（各分岐、5分以内、null）。
- 画面テスト: 津波タイルを固定の画像に差し替えて、浸水深の行と判定が出ること。浸水域外の文言。読めないときの注意。

## 7. 東海4県（静岡・愛知・岐阜・三重）への拡大

一つの計画で津波と一緒に行う（利用者の指定）。静岡は駿河湾沿岸で津波の到達が数分の地域が多く、§3 の「5分以内は判定を出さない」が多く当たる。

### 7.1 データ（県ごと。三重と同じ形にそろえる）

### 7.2 パイプライン

- `building_stock.py` など三重に固定された部分（県コード 24、ファイル名、表の見出し）を、県コードを引数に取る形に直す。三重の出力は変わらないこと（既存テストと、作り直した出力の一致で確認）。
- 市町村→メッシュの対応、避難場所の変換も県ごとに実行し、出力は県をまたいで一つの `public/data` にまとめる（2次メッシュ単位なので県境で重なるファイルは統合する）。
- 到達時間は `data/published/{pref}_tsunami_arrival.csv` に書き写し、公開用は一つの `tsunami_arrival.json`（市町村コード → 分）にまとめる。

### 7.3 答え合わせ

- 三重と同じ方法（代表曲線、県が使うケースに合わせたハザード）で、市町村別の全壊棟数を県公表値と比べる。県合計と、±30% に入る市町村の数を報告する。
- 県のケースが内閣府のどのケースに当たるかは報告書で確認し、ルールとして記録する。

### 7.4 画面・文言

- 「対応エリア：三重県」の表記を「静岡県・愛知県・岐阜県・三重県」に直す。対象外の地域は既存どおり「この地域はまだ対応していません」。
- 市町の補助制度の検索リンクなど、県名を含む文言を県ごとにする。
