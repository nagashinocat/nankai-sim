# 設計: いまいる場所から近い避難場所・簡易地図・電波なしで使う

状態: 2026-11-12 に利用者へ提示。利用者の返答「自宅に限らず現在地から近い緊急避難場所が出ると良い。地図は簡易地図で大丈夫」を反映した案。2026-11-14 に利用者 OK（「公開版も更新して」）。
2026-11-14 実装（branch `near-shelters`、計画 `docs/superpowers/plans/2026-11-14-near-shelters-offline.md`）。master への取り込み・公開はまだ。

実装メモ:
- コンパス: 新しい Chrome にも `DeviceOrientationEvent.requestPermission` があるため、許可のあとは `deviceorientation`（iPhone の webkitCompassHeading）と `deviceorientationabsolute`（Android の alpha）の両方を聞き、北の基準があるものだけ使う。3秒来なければ「北が上のまま」。
- 専用キャッシュ `nankai-offline-shelters-v1`（SW の版つき `nankai-sim-…` とは接頭辞が違うので activate で消えない）。保存した一覧（index.json）に無いファイルは電波なしでも 404（避難場所が無い2次メッシュ）。
- こどもモードでは保存の欄を出さない（おうちの人の操作）。

## 1. 新しい画面「📍 いまいる場所から近い避難場所」（#near）
- トップと結果画面に大きなボタン。押すと位置情報（GPS）で、近い順に 津波の避難場所5・地震の避難場所5 を出す
- 各避難場所に簡易地図（SVG）: いまの場所を中心、避難場所の方向と距離を矢印、北の向き、距離の目盛り、ほかの避難場所を薄く。文でも「北東へ 約350m・ゆっくり歩いて約6分」
- 向きを合わせる（コンパス、DeviceOrientation）: iPhone は許可が要る。使えない機種は北が上
- 自宅の結果の避難場所リストにも同じ簡易地図
- こどもモード: 大きな矢印と「この むきに ○m」
- 現在地は使うだけで保存しない
- 道順は出さない。図に「道は実際に確かめてください」

## 2. 電波なし
- 「避難場所のデータをこのスマホに保存」: 5県の指定緊急避難場所（data/shelters/*.json 370ファイル・約3.3MB）を Service Worker のキャッシュへ。保存日を表示、新しいデータがあれば更新をすすめる
- 電波なしの表示: 「電波がありません」＋できること（近い避難場所・前回の結果・家族の決まり）
- 津波の浸水想定は地理院タイルが要るので、電波なしでは「調べられません。海の近くなら揺れたらすぐ高い所へ」
- ホーム画面に追加（Web App Manifest・アイコン）
- 機内モードの e2e（playwright.offline.config.ts に追加）

## 3. 保存の範囲（利用者が選んだもの）
- 地図画像は保存しない（簡易地図だけ）
- 避難場所データ（公開データ）は端末に保存してよい
- 現在地・自宅の座標は保存しない

## 4. 制限
- アーティファクト（試作版のページ）は位置情報・Service Worker が使えない。試すのは Mac の試作（start.command）か公開後
