# 南海トラフ地震 自宅被害シミュレーター 設計書

- 作成日: 2026-11-12
- 状態: レビュー待ち
- 形態: 一般公開の Web アプリ（PWA、サーバーなし）

---

## 1. 目的と前提

### 1.1 目的
住所と建物の情報（築年代・構造）を入力すると、南海トラフ地震（および関連する地震）が起きた場合の
**自宅の被害の目安・自宅周辺の被害・避難場所**を示し、利用者を次の4つの行動につなげる。

1. 避難場所と避難経路の確認
2. 耐震診断・補強の検討（自治体の補助制度へ誘導）
3. 備蓄・家具固定などの備え
4. 家族との結果の共有

### 1.2 ユーザーが決めたこと
- 対象利用者: 一般公開（誰でも使える）
- 形態: Web アプリ
- 対象エリア: 南海トラフ地震の想定エリア全域
- 想定する地震: 全割れに加えて、A 半割れ・時間差発生、B 一部割れ、C 周辺の内陸活断層地震
- 運営費: ほぼ無料（サーバーを持たない）
- データ方針: 国（内閣府）の想定データを事前加工して使う（方法1）。県のオープンデータも併用する

### 1.3 設計上の仮定（ユーザー確認済みの設計に含まれる）
- 入力は住所・築年代・構造の3つ。構造は被害率への影響が大きいため必須の入力にする（「わからない」も選べる）
- 結果は統計的な目安であり、耐震診断の代わりではないことを明示する
- 一部割れ（B）は揺れの計算をせず、臨時情報への対応を体験する「練習モード」として作る
- 活断層（C）は南海トラフとの「連動」とは表現せず、「周辺の活断層の想定」として別枠で表示する

### 1.4 成功の基準
- 想定エリア内の任意の住所について、5秒以内（4G回線）に結果を表示できる
- 市町村ごとの揺れによる全壊棟数の合計が、公表値（国・県の被害想定）と ±30% 以内に収まる。収まらない市町村は「参考値」と表示する
- 一度結果を出した端末では、オフラインでも前回の結果と避難場所を見られる
- 住所を自前のサーバーに送らず、どこにも保存しない

### 1.5 対象外（今回は作らないもの）
- 個別建物の耐震診断（日本建築防災協会「誰でもできるわが家の耐震診断」へリンクで誘導する）
- 自宅単位の火災・土砂災害の計算（市町村全体の公表値を表示するだけにする）
- ネイティブアプリ、プッシュ通知、アカウント機能
- 広告

## 2. 既存サービスとの違い

| サービス | できること | 本アプリとの違い |
|---|---|---|
| 地震10秒診断（日本損害保険協会） | 現在地の震度確率、ライフライン停止日数、全壊確率 | 築年数を入力できず、南海トラフに限定した想定でもない |
| 地震ハザードカルテ（J-SHIS） | 住所の地盤・確率情報 | 建物被害・避難場所がない |
| あなたのまちの直下型地震（防災科研） | 直下型地震の被害シミュレーション | 南海トラフが対象外 |
| 誰でもできるわが家の耐震診断 | 自宅の簡易耐震評価 | 場所（揺れの大きさ）を考慮しない |
| 重ねるハザードマップ（国土地理院） | 各種ハザードの重ね合わせ | 建物被害の計算をしない |

本アプリの差別化: **南海トラフの想定 × 住所 × 築年代・構造 × 周辺被害 × 避難場所 × 行動への誘導**を1つにまとめること。

## 3. データの構成

### 3.1 共通の単位
すべてのハザード値を **250m メッシュ（5次地域メッシュ）** にそろえる。

### 3.2 メッシュごとに持つ値（想定ケースごと）
| 項目 | 内容 | 主な出典 |
|---|---|---|
| 計測震度 | 地表の震度 | 内閣府（データ提供申請）、県オープンデータ |
| PL値 | 液状化の起きやすさ | 内閣府、県 |
| 津波最大浸水深 | 沿岸部のみ | 国土地理院 重ねるハザードマップのオープンデータ（津波浸水想定）、県 |
| 津波到達時間 | 沿岸部のみ。入手できる地域のみ | 県の津波浸水想定 |

### 3.3 想定ケース
| ID | 内容 | データ |
|---|---|---|
| `L2` | 国の理論上最大クラス（全割れ） | 内閣府 2025年想定 |
| `L1` | 県の過去最大クラス | 各県の想定（ある県のみ） |
| `HALF_E` / `HALF_W` | 東側／西側の半割れ | 内閣府 2025年想定、県の半割れケース |
| `LAG_EW` / `LAG_WE` | 時間差発生（先発→後発） | `HALF_E` と `HALF_W` を順に重ねて計算（4.5 参照） |
| `FAULT_*` | 周辺の活断層 | 県の想定、または J-SHIS のシナリオ地震 |
| `PARTIAL` | 一部割れ（練習モード） | 揺れのデータは使わない |

基準は国の想定（`L2`）とする。県の想定がある地域では「県の想定に切り替える」ボタンを表示する。

### 3.4 建物データ（周辺被害の計算用）
- メッシュごとの建物数: 国土地理院 基盤地図情報（建築物外周線）から数える
- 築年代・構造の割合: マス単位のデータが公開されていないため、市町村単位の統計（住宅・土地統計調査）の割合を各マスに当てはめる。画面上では「推計」と明記する

### 3.5 被害関数
国の2025年想定の被害関数を表として持つ。
- 構造: 木造 / 鉄骨（S）/ 鉄筋コンクリート（RC・SRC）
- 建築年代: 1981年5月以前 / 1981年6月〜2000年5月 / 2000年6月以降
- 揺れ・液状化・津波それぞれについて、全壊率と半壊率を持つ

### 3.6 避難場所
国土地理院の指定緊急避難場所データを使う。災害の種類（地震・津波など）ごとの対応可否も含む。

### 3.7 ファイル配置
- 2次メッシュ（約10km四方）単位で、想定ケースごとの小さなファイルに分割する
- 無料の静的ホスティング（CDN つき）に置く
- 利用者の端末は、自宅周辺の1〜4ファイルだけを読み込む

### 3.8 出典と版の管理
- データセットごとに、出典・版・公開日・ライセンス・加工日を `manifest.json` に記録する
- 結果画面と説明ページに出典と版を表示する
- 元データが訂正されたら（例: 三重県は2026年6月に全市町の資料を訂正して差し替えた）、加工し直して版番号を上げる

### 3.9 内閣府データの入手先と利用条件（2026-11-12 確認済み）
- 入手先: G空間情報センター「強震断層モデル(1)データセットA」（内閣府 南海トラフ巨大地震モデル・被害想定手法検討会, 令和7年）。ログインが必要。250m メッシュ（4分の1地域メッシュ）の計測震度（Eq_*.csv、参考震度 Ia を使う）と液状化（Liq_*.csv、PL値・沈下量 S[m]）。ケースは 1〜5、最大クラス champ、半割れ 1E/1W/2E/2W。
- 利用規程: 加工した成果物は自由に頒布できる（第4条）。元データをそのまま、またはファイル形式だけ変えて頒布するのは禁止。出典「内閣府 南海トラフの巨大地震モデル・被害想定手法検討会」を明記し、加工したものを内閣府の未加工データのように見せない（第3条）。
- このため公開版のデータファイルは、生の震度表ではなく、本アプリで計算し直した値（被害率など）を配る。元データ（data/naikaku_raw/）は git に入れない。

### 3.9.1 当初の確認事項（参考）
| 確認事項 | 解決できなかった場合 |
|---|---|
| 内閣府提供データを Web で再配布（加工した形での公開を含む）できるか | 県のオープンデータ（例: 三重県は CC BY 4.0）がある県から公開し、ない県は「準備中」と表示する |
| 内閣府データに半割れケースのメッシュ値が含まれるか | 県の半割れデータがある県のみ第2版で対応する |
| 必要な出典表示の形式 | 内閣府・各県の指示に従う |

## 4. 計算の仕組み

すべてブラウザ内で計算する。

### 4.1 揺れによる被害
メッシュの計測震度と、建物の構造・年代に対応する被害関数から、全壊率と半壊率を出す。

### 4.2 液状化による被害
PL値から沈下量を推計し、国の手法で全壊率・半壊率に換算する。

### 4.3 津波による被害
浸水深に応じて全壊率・半壊率を出す。到達時間は避難判定に使う。

### 4.4 被害の合成
揺れ → 液状化 → 津波の順に、すでに壊れた分を差し引きながら足し合わせる（同じ建物を二重に数えない）。

```
残存 = 1
全壊 = 0
for 要因 in [揺れ, 液状化, 津波]:
    全壊 += 残存 × 全壊率(要因)
    残存 -= 残存 × 全壊率(要因)
```
半壊も同様に計算する。

### 4.5 時間差発生（国の手法）
内閣府の被害想定手法（概要 p.9）に従い、先発地震で半壊した建物は、後発地震に対して
「計測震度が 0.5 高い場合と同じ全壊率」で計算する。先発で無傷だった建物は通常の被害関数で計算する。
（2026-11-12 改訂: 当初の独自手法「ひとつ古い年代の曲線」から国の手法に切り替え）

### 4.6 周辺の推計
メッシュごとに「建物数 × 年代・構造の割合 × 被害率」を計算する。自宅から半径1km以内の推計全壊棟数を表示する。

### 4.7 幅の表示
- 想定震度を ±0.5 ずらして計算し、結果を「全壊 15〜25%」のような幅で表示する
- 年代や構造が「わからない」の場合は、すべての選択肢の最小値から最大値までを幅とする

### 4.8 耐震補強済みの扱い
「耐震補強をした」にチェックがあれば、ひとつ新しい年代の被害関数で計算する。

## 5. 画面の流れ

### 5.1 入力（1画面）
- 住所の入力、または「現在地を使う」
- 建築年: 1981年5月以前 / 1981年6月〜2000年5月 / 2000年6月以降 / わからない
- 構造: 木造 / 鉄骨 / 鉄筋コンクリート / わからない
- 階数（鉄骨・鉄筋コンクリートを選んだときだけ表示、任意）: 国の被害関数は S造 1〜4/5〜6/7〜15階、RC造 1〜6/7〜10/11〜15階で異なり、16階以上は揺れで損傷しないとされる。未入力なら全階数区分の最大値を使う
- 「耐震補強をした」チェック

### 5.2 結果
- 最初に「これは耐震診断ではなく、統計的な目安です」と表示する
- 想定の切り替えタブ: 最大クラス（L2）/ 過去最大（L1）/ 半割れ / 時間差 / 活断層（データがあるものだけ表示）
- **自宅**: 想定震度、全壊・半壊の確率（幅）、液状化、津波の浸水深・到達時間
- **周辺**: 地図上にマスごとの全壊率を色で表示、半径1km以内の推計全壊棟数
- **避難**: 災害の種類で絞り込んだ近くの避難場所と徒歩時間。津波地域では「到達時間までに着けるか」を色で示す（徒歩速度は高齢者を想定した遅めの値も選べる）
- 時間差タブは「先発 → 後発」の2段階で表示する
- 火災・土砂災害は市町村全体の公表値を表示する

### 5.3 行動カード（結果の下）
| カード | 内容 |
|---|---|
| 避難 | 避難場所までの経路を地図アプリで開く |
| 耐震 | 市町村の耐震診断・補強補助制度のページへのリンク、「誰でもできるわが家の耐震診断」へのリンク |
| 備え | 震度と被害に応じた備蓄・家具固定のチェックリスト（端末内に保存） |
| 共有 | 家族向けの結果カード画像。初期設定では住所を含めず、市町村名と結果だけにする |

### 5.4 練習モード（一部割れ）
「南海トラフ地震臨時情報（巨大地震注意）が発表された」という場面から始め、その後1週間の行動を選択式で体験する。

### 5.5 説明ページ
計算方法、データの出典と版、制約（推計であること・独自手法の部分）、プライバシー、自治体の公式ハザードマップへのリンク。

## 6. エラー時の扱い

| 状況 | 対応 |
|---|---|
| 住所が見つからない | 地図上でピンを動かして場所を指定してもらう |
| 想定エリアの外 | 「南海トラフの想定では大きな揺れは想定されていません」と表示し、J-SHIS の確率情報を参考として出す |
| データがないマス（山林など） | 計算せず「データなし」と表示する。推測で埋めない |
| 公表値との照合で大きくずれた市町村 | 結果に「参考値」と表示する |
| データファイルの読み込み失敗 | 再試行ボタンを出す。前回の結果が保存されていればそれを表示する |
| オフライン | 保存済みの前回結果と避難場所を表示する |

---

## 7. プライバシー
- 住所・結果は自前のサーバーに送らない（サーバー自体を持たない）
- 住所を座標に変換するときは国土地理院の住所検索 API を使う。このことをプライバシー説明に明記する
- 前回の結果は端末内にのみ保存し、ボタン1つで消せるようにする
- アクセス解析を入れる場合は、住所や座標を送らない設定に限る

---

## 8. 表現とアクセシビリティ
- 数字は幅で示し、必ず行動カードにつなげる。不安をあおるだけで終わる表現は避ける
- 文字を大きくし、色だけに頼らない表示（数値・ラベルを併記）にする
- 自治体の公式ハザードマップへのリンクを必ず出す

## 9. 構成要素

| 要素 | 役割 | 依存先 |
|---|---|---|
| データ加工パイプライン（オフライン） | 元データ → 250mメッシュ → 2次メッシュ単位のファイル、`manifest.json` の生成 | 元データ |
| 照合スクリプト（オフライン） | 市町村の合計を公表値と比べ、ずれの大きい市町村リストを出す | パイプラインの出力、公表値の表 |
| `geocode` | 住所 → 緯度経度 | 国土地理院 API |
| `mesh` | 緯度経度 → メッシュコード、周辺メッシュの列挙 | なし |
| `hazardLoader` | 必要なファイルの取得とキャッシュ | 静的ファイル |
| `damage` | 被害関数、合成、時間差、幅の計算（純粋関数） | 被害関数の表 |
| `neighborhood` | 周辺の推計 | `damage`、建物データ |
| `evacuation` | 避難場所の絞り込みと徒歩時間 | 避難場所データ |
| UI | 入力・結果・行動・練習モード・説明 | 上記すべて |
| Service Worker | オフライン対応 | なし |

`damage` は入力（震度・PL値・浸水深・構造・年代）だけから結果が決まる純粋関数にし、単体でテストできるようにする。

---

## 10. テスト
- `damage`: 被害関数の代表点（構造 × 年代 × 震度）を元資料の値と照合する単体テスト。合成で全壊＋半壊が100%を超えないこと
- `mesh`: 既知の座標とメッシュコードの対応（例: J-SHIS の公開カルテのメッシュコードと中心座標）
- 照合テスト: 市町村ごとの揺れによる全壊棟数の合計を公表値と比べる。最初の基準は三重県菰野町（L2 の揺れによる全壊 約1,400棟、L1 約40棟）
- 画面: 入力 → 結果 → 行動の一連の流れ、オフライン時の表示
