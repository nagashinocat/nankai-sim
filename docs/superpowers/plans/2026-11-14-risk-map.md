# 倒壊と津波の「やることマップ」実装計画

> subagent-driven。branch `risk-map`。デザイン: `docs/design/risk-map/Main.dc.html`（おとな）・`Kids.dc.html`（こども）。2026-11-14 利用者 OK ＋「高台とか避難場所はもっと目立つように」。

**Goal:** 結果画面の周辺1km地図を、倒壊と津波の組み合わせを「やること」で塗る地図にし、避難場所（高い所）と逃げる方向をいちばん目立たせる。こどもモードにも地図を出す。

## Global Constraints
- 日本語。計算（src/core）、Saved v4、共有文は変えない。住所・座標は保存しない。
- 色だけに頼らない: 津波は波の模様（ハッチ）も付ける。凡例は「やること」の言葉。
- 「安心させすぎない」: 灰色は「比較的低い（備えは同じく必要）」。「灰色も安全という意味ではありません。想定を超える揺れや津波もあり得ます」を地図の下に。
- 逃げる方向の矢印は直線: 「直線の方向と距離です。道は実際に確かめてください」。
- 分け目: 倒壊「大きい」＝そのマスの全壊率の推計（中央値）10%以上。「中」＝1%以上10%未満（揺れモードのみ使う）。津波「あり」＝そのマスの津波深（`areaTsunamiDepth` の結果）が 0 より大きい。津波が判定できない（null）マスは津波なし扱いにせず、模様なしの「判定できません」色（薄い灰に斜線）にする。
- 既存の出典表示・凡例の出典（ハザードマップポータルサイト、加工の旨）は残す。

## Review Focus
1. 避難場所の印が、マスの色・津波タイル・自宅の印の下に隠れない（常にいちばん上、ズームしても読める）。
2. 自宅が浸水域外・津波 unknown・対応範囲外のとき、矢印と「自宅はここ」の文が正しい（浸水域外なら矢印は出さないか「念のため」の弱い表示）。
3. 揺れ/津波/両方の切りかえで、凡例・読み上げの文・自宅はここ が一緒に変わる。タブ（想定ケース）を変えても選んだモードが残る。
4. こどもモードの地図: 文字はひらがな、赤は「にげる」だけ。
5. 地図タイルが読めない（電波なし）ときも、マス・避難場所・矢印・凡例は出る。

## Tasks
1. **純粋関数** `src/app/riskmap.ts`（+ tests）: `cellClass(rate:number|null, tsunamiDepth:number|null): {collapse:'high'|'mid'|'low'|'none', tsunami:'yes'|'no'|'unknown'}`、`cellFill(cls, mode:'shake'|'tsunami'|'both'): {fill, hatch:boolean, unknownHatch:boolean}`（色はデザインどおり: 両方 #8E7CC3、津波 #8FBCE8、倒壊大 #E8A33D、倒壊中 #F6D58E、低 #E3E1DA/#EEEBE3）、`legendFor(mode, kids)`、`homeQuadrant(homeRate, homeTsunamiKind)` → {key, title, action}、`escapeTarget(home, tsunamiShelters, tsunamiKind)`（band/nearby のとき最寄りの津波の避難場所。none/unknown は null）と方向文（minimap.ts の bearing/dir8 を使う）。
2. **地図**（`ui/map.ts`、`ui/result.ts`）: 地図の上に「揺れ／津波／両方」切りかえ（既定は両方、aria-pressed、選択はメモリでタブ間で保持）。マスを cellFill で塗り、模様は Leaflet の SVG に `<pattern>` を足して重ねる。津波モードのときだけ地理院の津波タイルを重ねる（両方モードはマスだけ）。**避難場所の印**: 津波の避難場所は大きな緑の丸（直径36px程度、白い縁、上向きの山＋矢印の形、番号）と名前のラベル（白地・緑の枠・太字）、地震の避難場所は小さめの青緑の印と番号。専用ペイン（z-index 650、自宅の印より上でもよいが自宅と重なったらずらす）。凡例に「津波の避難場所（高い所）」「地震の避難場所」。**逃げる方向**: 自宅→escapeTarget へ太い緑の矢印（Leaflet polyline＋矢じり）と「逃げる方向」ラベル、地図の下に「津波の避難場所「1」へ 北西に約450m（直線。道は実際に確かめてください）」。**自宅はここ**: 地図の下に 2×2 の小さな図と点＋homeQuadrant の文。
3. **こどもモード**（`ui/kids.ts`）: 両方モードだけの地図（同じ部品、kids オプション）。大きな「おうち」印、津波の避難場所は「にげる ばしょ」ラベル、太い矢印、凡例はデザインの3行（ひらがな）、下に「ゆれが とまったら すぐ みどりの やじるしの ほうへ にげる」（赤枠）。地図タイルが無くてもマスと印で読める。「はいいろの ところも、ゆだんは しないでね」。
4. **テスト・仕上げ**: e2e（切りかえで凡例が変わる、避難場所の印とラベルが出る、矢印の文、こどもモードの地図、390px はみ出しなし、タイル読めないときも凡例とマスが出る）。390×844 のスクショを reports/ に撮って見る。`docs/HANDOFF.md` の「できていること」に追記。
