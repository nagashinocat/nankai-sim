# 一部割れ練習モード Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 「南海トラフ地震臨時情報（巨大地震注意）が発表された」場面から1週間の行動を選択式で体験する練習モードを作る（設計書 §5.4）。

**Architecture:** 場面と選択肢は `src/app/practice/scenes.ts` のデータ（下の文言をそのまま使う）。画面は `src/app/ui/practice.ts`。結果画面と説明ページから入れる。自宅の結果があれば、津波の到達時間に応じた一言を最後に足す。通信なし・保存なし（進み具合は画面内だけ）。

**Spec:** `docs/superpowers/specs/2026-11-12-nankai-trough-sim-design.md` §5.4。根拠: 内閣府「南海トラフ地震臨時情報（巨大地震注意）」資料 https://www.bousai.go.jp/jishin/nankai/rinji/pdf/r8pdf03.pdf 、気象庁 https://www.jma.go.jp/jma/kishou/know/jishin/nteq/info_criterion.html

## Global Constraints

- 入口のボタン: 「臨時情報が出たら？ 1週間の練習」。画面の見出し: 「練習モード：南海トラフ地震臨時情報（巨大地震注意）」
- 冒頭の注意（常に表示）: 「これは練習です。臨時情報は地震の予知ではなく、発表されても実際に地震が起きるかはわかりません。実際に発表されたときは、テレビ・ラジオ・自治体の情報に従ってください」
- 場面（この順、各場面は「状況」「問い」「選択肢（1つが最適）」「解説」）:
  1. 0日目 夜: 状況「南海トラフ沿いでM7クラスの地震が起き、『南海トラフ地震臨時情報（巨大地震注意）』が発表されました。あなたの住む地域では大きな被害はありません」。問い「今夜、どうしますか？」。選択肢: (a)「すぐ逃げられる服装で寝て、非常持出品を枕元に置く」【最適】 (b)「念のため家族全員で避難所に泊まりに行く」 (c)「いつもどおりパジャマで寝る」。解説「巨大地震注意では事前の避難は求められません。日頃の備えを確かめ、すぐ逃げられる態勢をとったうえで、普段の生活を続けます」
  2. 1日目 朝: 問い「仕事や学校はどうしますか？」。(a)「普段どおり行くが、非常持出品を持ち歩く」【最適】 (b)「1週間は家から出ない」 (c)「何も持たずに普段どおり行く」。解説「社会経済活動は続けます。そのうえで、非常持出品を常に持ち歩くなどの『特別な備え』をします」
  3. 2日目: 問い「家の中で確かめておくことは？」。(a)「避難場所と避難経路、家族との連絡方法、家具の固定、備蓄を確かめる」【最適】 (b)「水と食料を大量に買い足す」 (c)「特に何もしない」。解説「日頃からの備えの再確認が呼びかけられます：避難場所・避難経路の確認、家族との連絡手段の確認、家具等の固定、非常食などの備蓄の確認」
  4. 3日目 夜: 問い「どの部屋で寝ますか？」。(a)「倒れてくる家具がない、なるべく安全な部屋」【最適】 (b)「いつもの部屋（たんすの横）」 (c)「車の中」。解説「屋内のできるだけ安全な場所で過ごし、寝るときもすぐ逃げられるようにします」
  5. 5日目: 状況「SNSで『今週中に必ず巨大地震が来る』という投稿が広まっています」。問い「どうしますか？」。(a)「気象庁や自治体の情報を確かめ、むやみに広めない」【最適】 (b)「家族や友人にすぐ転送する」 (c)「怖いので情報を見ないようにする」。解説「臨時情報は地震の予知ではありません。公式の情報を確かめましょう」
  6. 7日目: 状況「地震発生から1週間が過ぎ、特別な注意の呼びかけが終わりました」。問い「これからは？」。(a)「普段の生活に戻るが、地震の可能性がなくなったわけではないので備えは続ける」【最適】 (b)「もう大きな地震は来ないので、非常持出品を片づける」 (c)「念のためあと1か月は家から出ない」。解説「呼びかけは1週間（地震発生から168時間経過した以降の正時まで）です。終わっても大規模地震の可能性がなくなったわけではありません」
- まとめ（最後の画面）: 最適を選んだ数「6問中 n問」と、次の一文: 「『巨大地震警戒』が出た場合は、地震が起きてからの避難では間に合わないおそれのある地域で、1週間の事前避難が求められます。お住まいの地域が対象かは市町村に確認してください」
- 自宅の結果がある場合（その端末の画面内で直前に出した結果）、まとめに一行追加: 津波の到達時間が10分以内または津波の段階あり →「あなたの家は津波の到達が早い／浸水が想定される場所です。『巨大地震警戒』のときに事前避難の対象になっていないか、市町村に確認してください」。津波の想定が判定できなかった（unknown。上の条件に当てはまらないとき）→「津波の想定を確かめられませんでした。お住まいの市町村のハザードマップで確認してください」（Ruling P1）。それ以外 →「揺れへの備え（家具の固定・耐震）を確かめておきましょう」
- 選んだ直後に正誤と解説を出し、「次へ」で進む。戻る・最初からやり直す ができる。キーボード操作可、390px で読める。出典リンク（上の2つ）を最後に表示。
- 住所・座標は扱わない。保存しない。

## Review Focus
1. 文言が上のとおり（勝手に断定を増やさない）。2. 自宅の結果がないときもまとめが出る。3. 途中でやり直しても点数が混ざらない。4. 結果画面から入って戻ると結果が残っている。5. 練習であることが常に分かる。
